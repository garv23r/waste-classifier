# EcoVision - Smart Waste Intelligence

EcoVision is an AI-powered web application designed to help individuals make informed and environmentally responsible waste disposal decisions. By combining machine learning with localized waste management rules, EcoVision simplifies sustainability for everyday users.

**Live Application:** https://ecovision-waste-classifier.streamlit.app/

<br>

## Overview

EcoVision bridges the gap between advanced AI technology and real-world environmental challenges. It uses deep learning models trained on waste classification datasets and integrates region-specific disposal rules (Sarnia, Ontario) to guide users on proper waste handling.

<br>

## Features

- **AI-Based Waste Classification**  
  Identify and classify waste items using trained machine learning models.

- **Location-Specific Disposal Guidance**  
  Provides disposal instructions based on Sarnia’s municipal waste regulations.

- **Environmental Awareness**  
  Includes interactive facts to educate users about the environmental impact of waste.

- **User-Friendly Interface**  
  Built with Streamlit and enhanced with custom styling for a clean experience.

- **Circular Economy Approach**  
  Encourages responsible practices such as reducing, reusing, and recycling correctly.

- **Feedback Integration**  
  Allows users to submit feedback through an embedded form.

<br>

## Tech Stack

- **Frontend/UI:** Streamlit with custom HTML/CSS  
- **Backend:** Python  
- **Machine Learning:** Neural Networks (Deep Learning)  
- **Dataset:** Kaggle Waste Classification Dataset  
- **Deployment:** Streamlit Cloud

## Vision

## Circular Economy Model

EcoVision follows the principle:

Reduce → Reuse → Recycle (correctly)

The goal is not only to promote recycling but to ensure it is done properly.
